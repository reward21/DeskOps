## Scope

Chat can use Quant's existing strategy, gate, matrix and research configuration
tools. Buttons provide direct calls for common actions; configuration inspection
shows the backtest configuration, strategy, gate, matrix and research settings.
Accepted work survives page reloads, but an operating-system restart still ends
workers and is reported as interruption. Model proposals can still be wrong;
the GUI does not establish profitability or remove the need to inspect results.
